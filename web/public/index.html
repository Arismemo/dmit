自建网络架构图

更新日期 2026-11-04。覆盖三台海外服务器（DMIT、RAK、AWS）上运行的节点服务、本机代理链路、模型服务链路与管理通道。 源文件在仓库 /Users/liukun/j/dmit/web/public/index.html，网络有变更时必须同步改这个文件并重新部署。

2026-10-26 起，DMIT、RAK、AWS 三台的公网 TCP 从国内被封（回程丢包），UDP 不受影响。因此只有走 UDP 的 DMIT-HY2 与 RAK-HY2 稳定可用，Reality 节点会时好时坏。订阅地址同样走 TCP，从国内直接拉会失败。

Claude 隔离环境靠 Linux 网络命名空间实现：命名空间内只有回环网卡，没有默认路由，任何忽略代理的直连都会失败而不是绕到机房出口。主网关 Magpie 通过 Unix socket 转发进隔离环境，不附加转发头。模型列表可读不等于能真实调用。

公网 TCP 被封后，Tailscale 是管理这些机器的主通道；Rak 的 SSH 端口是 28827，DMIT 走默认端口 22。公网 SSH 走不通不代表机器出问题。
