# 独立实例工具（开发中）

现有服务与 Magpie 共用原隔离网络。新增实例不得覆盖现有服务、网络命名空间或凭据。

`instance-runtime.py` 是实验性运行时，尚无完成的实例安装器、故障回滚和端到端验证，不能用于生产，也不能单独执行创建操作。后续安装器需要实现独立账户、命名空间、住宅代理桥、受限私有 socket 和 systemd 单元，以及交互式读取凭据、端口冲突检查和失败回滚。

安全边界：网络命名空间共享主机内核；系统管理员或拥有相应权限的进程仍可改变网络环境。启动时校验出口不能保证运行期间的出口不发生变化。用户目录内的客户端和启动参数也不应视为对该用户的安全边界。
